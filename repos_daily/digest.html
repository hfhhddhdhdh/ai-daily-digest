1. umbradev315/ffmpeg-video-audio-converter

⭐ 1,188・4 天新项目・Kotlin

它是干啥的：给 FFmpeg 套了个窗口界面，点点鼠标就能转视频

解决什么麻烦：手机拍的视频格式不兼容、文件太大发不出去、想把一整批录像统一转成小一点的格式——以前只能对着黑框敲命令，现在有按钮和进度条可以点，还能顺手比一比转前转后的画质。

怎么用：在 Windows 上装这个图形界面程序，转换、批量处理、画质分析都在窗口里完成，免费开源，不用注册账号。

多少人用：四天 1188 星。

要注意：选项很多，第一次打开会有点懵；转大文件很吃处理器，老电脑会发烫变慢。

值得试｜不用敲命令，处理视频正合适

2. Pixel679-cmyk/windows-titlebar-blur-customizer

⭐ 1,506・1 天新项目・C++

它是干啥的：把 Windows 窗口顶上那条标题栏改成磨砂玻璃效果的小工具

解决什么麻烦：每天对着电脑，窗口最上面永远是一条死板的纯色横条，看久了很闷。想让窗口像别的系统那样透出后面的壁纸，系统自带的外观设置里压根没这个选项。

怎么用：面向 Windows 10 和 11，提供几种不同质感的模糊样式；是否需要自己编译、收不收费，得看它的说明文档。

多少人用：一天就有 1506 星。

要注意：是 C++ 写的，如果作者没打包现成安装包，就得自己编译，新手会卡在这一步；改系统外观也可能和个别软件打架。

看看就好｜效果好看，但可能要自己动手装

3. Basil0879/steam-game-idler

⭐ 1,224・4 天新项目・TypeScript

它是干啥的：帮你在 Steam 上挂游戏时长、刷卡牌、管成就的工具

解决什么麻烦：Steam 上玩够时长会掉集换式卡牌，可以拿去卖钱或换徽章。有些人没空一直开着游戏，或者手里有几个账号懒得挨个登，就想让程序替自己挂着。

怎么用：在 Windows 上运行，需要登录你的 Steam 账号，支持同时管多个账号；收不收费得看它的说明。

多少人用：四天 1224 星。

要注意：要把账号交出去，自动挂机也可能违反 Steam 的用户协议，有被封号的风险。

看看就好｜能省事，但拿账号去冒险

4. Nebula4207/av1-video-encoder-gui

⭐ 1,107・4 天新项目・C#

它是干啥的：把视频压成 AV1 格式的图形界面工具

解决什么麻烦：AV1 是新一代视频压缩格式，同样画质文件更小，传到网盘、发给朋友都省事。但支持它的编码工具有好几种，参数全是英文缩写，普通人根本不知道该挑哪个、填什么。

怎么用：Windows 程序，把几种编码方式收进一个窗口；要不要另外装组件、收不收费，得看它的说明文档。

多少人用：四天 1107 星。

要注意：AV1 编码很慢，一段视频可能压很久；参数没调好画面反而更糊，适合愿意慢慢研究的人。

看看就好｜能压更小，但要花时间摸参数

5. trustno1-coder/VIctory-NVIDIA

⭐ 4,363・2 天新项目・Rust

它是干啥的：让 Xbox 游戏在装了英伟达显卡的电脑上跑起来的一层翻译

解决什么麻烦：你手里有 Xbox 版的游戏，想在电脑上打开，结果发现根本进不去，因为主机和电脑说的不是同一种话。这个项目就是在中间做翻译，还顺手调了画面流畅度和帧数补偿。

怎么用：游戏文件得你自己准备，它既不带游戏，也不带显卡厂商的文件；具体怎么装、几步走，得按它的说明文档来，免费。

多少人用：两天涨到 4363 星。

要注意：只在特定型号的 RTX 显卡上调过，配置不对就白忙；没有游戏本体的人基本跑不起来。

别急｜要自备游戏文件，新手只会越弄越乱
