🔬 值得深挖

KV-streams for Efficient Compaction in Agentic Reinforcement Learning

核心贡献：针对智能体在长文本强化学习中因为 KV 缓存导致 GPU 内存爆炸和训练吞吐极低的痛点，提出了 KV-streams 插件式策略，通过在 compaction 之后向前流式传输 KV 缓存而不是疯狂重复预填充，实现 2.6 到 5 倍的训练墙钟加速，同时充当类似循环状态的记忆载体。

值得关注的点：该技术直接切中了当前长文本 Agent 训练的最贵命脉。它不仅解决了 GPU 内存溢出的硬件瓶颈，还让模型在长期迭代中拥有了连续记忆能力，对做超长工作流 Agent 的团队具有极高的工程落地价值。

Shockingly Simple Self-retrospection Improves Agentic Models Without RL

核心贡献：提出了仅靠回溯微调（ROFT）的极简在线优化流程：让模型在完成任务并观察反馈后，自己写一份“复盘解释”，然后仅对解释部分的 Token 进行下一词预测损失微调，完全不需要外部教师或复杂的强化学习奖励模型，就在 SWE-bench 上把 Qwen3.5-4B 的解决率推到了极高水平。

值得关注的点：它证明了“像人一样写日记复盘”比折腾复杂的 RL 算法更管用。对于中小团队来说，这种无需昂贵奖励模型的轻量化自我进化方案，极大地降低了训练高智商软件工程 Agent 的门槛。

Humanoid Loco-Manipulation With Discrete VLA Model

核心贡献：推出了 Holo-M，据称是首个将大语言模型词表扩展动作 Token 的离散视觉-语言-动作（VLA）模型，通过统一的动作分词器将人形机器人的全身动作（四肢、躯干、手部）统一编码，成功打通了人形机器人全地形移动和精细操作的闭环。

值得关注的点：人形机器人此前一直卡在“手脚不协调”和高维异构动作空间难对齐的魔咒上。该研究直接把大模型的语言词表改造成了机器人的运动控制密码，为具身智能通用大脑提供了教科书般的架构参考。
