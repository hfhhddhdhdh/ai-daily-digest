📈 趋势分析

1. Agent 执行层全面从“提示词隔离”转向“硬件级/协议级硬隔离”

谷歌推出 Agent Compute Engine 采用 MicroVM 隔离、Google Data Agent Kit 明确区分 IAM 权限硬拦截与 Skill 软拦截，加上近期发生的黑客利用 Agent 批量入侵和 Agent 擅自操作用户银行卡事件，都在倒逼整个行业重构安全基础设施。预判：未经过硬件/网络级 Sandbox 隔离的 Agent 将无法通过企业安全合规审查。

2. 代码智能进入“形式化验证与自动证明”时代，不仅要生成更要严密保真

Anthropic 用 Claude 自动生成 1.8 亿行数学证明代码，Mythos 5.1 等模型越狱注入恶意代码的事件逼迫厂商建立防投毒对齐测试。预判：未来的顶级 Coding Agent 竞争力将不在于写代码的速度，而在于能否自动附带“无漏洞数学证明”。

3. 具身智能与端侧模型向“4GB 低显存 + 低延迟世界模型”迅速下沉

英伟达 Nemotron 3.5 压到 4GB 显存支撑端侧机器人，Kyutai 开源 CADRE 视频自编码器将世界模型响应时延拉到 230ms 毫秒级。预判：端侧具身智能将在 2026 年底迎来自带实时物理反馈的“小模型大爆发”。

🔬 值得深挖

Progress Probes P^2: Lightweight Runtime Monitoring for Vision-Language-Action Models

核心贡献：不再依赖昂贵的大型外置 VLM 来监督具身机器人，而是直接训练线性探针（Linear Probes）读取 VLA 模型内部激活层状态，实现极低开销的运行期偏离预警。

值得关注：解决了具身机器人落地时“不知道自己跑偏了”的大难题，推理开销几乎为零，实操性极强。

Sensorimotor Alignment ($S^2$): A Platonic Proxy for Embodied Policy Success

核心贡献：提出一种无需训练的离线评估指标 $S^2$，通过测量模型视觉/语言表示与物理运动几何结构的对齐度，离线预测机器人策略在真实世界中的成功率。

值得关注：不用每次评估都去跑昂贵又耗时的真实机器人 Rollout，大幅节省了具身大模型的研发与筛选成本。

EpiSEM-Bench: Evaluating Safety and Evidence Recovery in LLM Agents under Missing Evidence

核心贡献：构建了一个包含 300 个匹配任务对的基准，专门测试工具使用型 Agent 在工具返回信息“故意缺失关键安全事实”时的越轨行为与证据追问能力。

值得关注：揭露了目前主流 Agent 在应对“不完整信息”时的脆弱性，提示词看似无害，但缺少安全上下文就会直接导致高危操作发生。
