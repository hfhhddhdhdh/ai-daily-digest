📈 趋势分析

1. 基础设施面临“民意与预算”双重挤压，AI 扩能进入精细化时代

中期选举中 40 项限制数据中心议案的通过与 Ramp 展现的企业 AI 支出平缓，传递出一个明确信号：大搞粗放式算力堆砌不仅面临物理资源与政策管辖的强烈反弹，更面临买方市场的理性算账。接下来整个行业将被迫从“拼算力规模”转向“拼推理效率”、“拼工程优化（如 KV 缓存感知）”和“拼端侧小模型”。

2. 代码 Agent 迈入“工程落地阵痛期”，Spec 与安全审查成为刚需

从阿里 Co-Design Bench 测试中 GPT-6 Astra 仅 26.4% 的真实解决率，到 Grab 坦承 AI 代码引发应用崩溃，事实证明只凭单次提示词生成代码会带来庞大的技术债务。行业正迅速转向 Spec 优先（如谷歌 Elephant-Goldfish 插件）、沙箱自动验证攻击（如 AWS Continuum）以及 Agent 权限监控（如 Palo Alto 巨额收购 Clutch），编码自动化正在重构整个 DevSecOps 流程。

🔬 值得深挖

On Agentic Manipulation Policies (AMP1)

核心贡献：论文提出了 AMP1 框架，证明通用大模型在无需演示数据或特定任务训练的情况下，通过直接向机器人机械臂下发高层指令并实时调整，其零样本操控成功率远超专用的视觉-语言-动作（VLA）模型和世界-动作模型（WAM）。在 RoboLab-120 基准上，AMP1 取得了 85.6% 的零样本成功率，而顶尖 VLA 仅为 49.2%。

关注点：具身智能领域长期存在“专用微调”与“通用调配”的路线之争。该研究表明，通用大模型的推理与规划能力可以直接跨界解决复杂物理操控问题，大幅降低了机器人训练的门槛。

CPU-ARC: Agentic Reasoning Caching for on-CPU Reasoning Reuse

核心贡献：针对大模型反复“重新发明轮子”导致的计算浪费，研究团队提出 Agentic Reasoning Caching (ARC)。该技术将大模型生成的推理轨迹编译提取为可在标准 CPU 上高效执行的程序逻辑。在保持与顶级 LLM 相当的科学解题准确率的同时，调用成本降低了 16 至 291 倍。

关注点：大模型推理成本居高不下，ARC 提供了一种“大模型思考一次，低成本 CPU 复用无数次”的极佳降本思路，非常适合规律性强的工业与科学计算工作流。

Test-Time Compute Scales Better with Parallel Agent Teams

核心贡献：研究探究了测试时计算量（Test-Time Compute）扩展的最优范式。实验表明，相较于部署单只包含 100 个 Agent 的超大团队或并行运行 100 个独立 Agent，采用“并行采样多个小团队（如 10 个成员的小组并行）并挑选最佳输出”的策略，在同等算力成本下表现最佳，成功率甚至超越了顶级闭源大模型。

关注点：为多 Agent 协作系统在复杂推理与工程破解任务中的架构设计提供了明确的算力分配指导策略。
