🔬 值得深挖

Scaling Discovery Requires Forgetting

核心贡献：这篇论文直面了 LLM 智能体在做自动化研究和长周期探索时的一个死胡同——随着历史对话和尝试不断累积，智能体会陷入自我锚定，编辑动作越来越小，最终性能停滞不前。作者提出了一种极为反直觉但极其有效的策略：周期性地“遗忘”（Periodically Forgetting），定期丢弃所有智能体的历史会话和中间状态，只保留当前找到的最佳候选重新出发。 关注点：在 Agent 长期运行和科研探索中，“断舍离”比死磕历史记忆更重要，这为未来长文本、多步骤 Agent 的架构设计提供了颠覆性的优化思路。

AdaRSI: On-Demand Recursive Self-Improvement for Embodied Agents

核心贡献：针对具身智能（如 RoboCasa 场景中的机器人）在长周期任务中半路卡壳的问题，提出了一种按需递归自我改进框架（AdaRSI）。它不搞盲目的一刀切微调，而是让代码智能体先诊断失败的子步骤，重试失败状态，并且只对那些依然不可靠的子步骤利用自己收集的数据和前期经验进行定向微调。 关注点：在没有人类演示的情况下，具身智能模型如何实现低成本的自我纠错与能力进化，这为机器人在真实复杂环境中的自适应提供了清晰的工程落地模板。
