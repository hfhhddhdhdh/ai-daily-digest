从谷歌 Gemini Robotics 2.5 在奔驰总装线做到 96% 的零部件分拣成功率，到英伟达 GR00T 2 直接通过人类视频吸收动作泛化能力，具身智能正在快速摆脱过去只能在特定演示台抓取方块的“玩具阶段”。大模型的泛化能力结合机器人视觉，让复杂环境下的机械控制有了实用价值。预计未来一年内，汽车、电子制造等标准化程度较高的流水线上，替换特定重复岗位的通用具身机器人将开启小批量工业预派驻。

2. 企业级 Agent 架构去“纯 LLM 化”：高频确定性流程回归代码控制

本期 arXiv 论文 ReTrace 以及沃尔玛 4700 家门店的多 Agent 实战表明，纯靠 LLM 在每一步做推理决策不仅成本高昂，而且不稳定。行业开始转向“大模型负责拆解 SOP 并生成规则，生成后交由确定性的代码逻辑去执行”的模式。这种“Planner-Free（无规划器）”的工作流能直接降本 20% 以上。纯 LLM 决策将退守到异常处理环节，确定性代码流水线将重新统治高频业务。”

3. 交互形态全面微型化：从百亿参数下沉至极低延迟边缘端

Meta Muse Ember 把 100 万上下文模型的推理单价压到 Haiku 5.5 的三分之一，Fish Audio 把双工语音响应时间缩短到 186 毫秒，Zyphra 则把 TTS 模型激活参数缩小到 1 亿并搬进了浏览器。这一切都指向同一个信号：Agent 正在脱离云端计算依赖，向智能手表、浏览器甚至离线终端转移。响应时间压到 200 毫秒以内后，以语音为核心的“无感交互”将彻底取代传统 UI 界面。

🔬 值得深挖

ReTrace: Distilling Tool-Using Agents into Planner-Free Workflows

核心贡献：论文提出了 ReTrace 框架，能够把大模型 Agent 在执行标准 SOP 时的推理过程蒸馏提炼出来，转化为不需要 LLM 参与决策的静态代码工作流（Code-based Workflows）。在 79 个生产环境的标准作业流程中，ReTrace 编译出的代码工作流不仅达到了 93.8% 的完成率（对比纯 Agent 的 96.8%），更将单次任务成本直接砍掉了 24%。

关注理由：治好了很多企业“Agent 运行成本太贵用不起”的病。它提供了一条将 Agent 探索出来的知识转化成固定代码的清晰路径，对于想要降低 Agent 线上部署成本的工程团队来说是极佳的参考范式。

One Policy for 100 Household Tasks: Our Solution for the 2026 BEHAVIOR Challenge

核心贡献：作者团队展示了如何在 OmniGibson 仿真器中，仅仅依靠单个 VLA（视觉-语言-动作）模型 Checkpoint，就同时学会并驾驭 100 种长时程（Long-horizon）复杂家庭家务任务。该方案基于 $\pi_{0.5}$ 架构，打破了以往一种家务对应一个独立控制模型的局限，在 100 项测试中取得了 0.392 的综合得分。

关注理由：证实了具身智能领域“欠训练（Undertrained）”的假设——不需要复杂的架构大改，只要通过优化数据表达、延长训练时间并降低梯度噪声，单个通用策略模型就能同时处理极为多样的物理操作任务。

Earlybird: Predictive Streaming Speech Recognition in 29M Parameters

核心贡献：提出了仅有 29M 参数（4-bit 量化后仅 16.8 MB）的超轻量预测型流式语音识别模型 Earlybird。它打破了传统“等说话人讲完词再输出”的逻辑，能在用户话还没讲完时，提早 90 毫秒预测出正在说的词以及接下来的单词，全面超越现有流式模型。

关注理由：极度适合端侧语音 Agent。把语音识别的延迟直接拉成了“负数”（提前预测），给下游的 LLM 思考争取到了极其宝贵的几十毫秒时间窗口，是构建无缝对话体验的重要技术拼图。
