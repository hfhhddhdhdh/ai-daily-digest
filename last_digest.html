🔬 值得深挖

DART: 挖掘被拒绝的推理轨迹，硬核数学难题恢复率直接提升 37%

核心贡献：针对高难度数学难题在 Monte Carlo (MC) 采样中极其容易全盘失败（得到全错轨迹）的痛点，论文提出了 DART（多样化替代推理轨迹）方法。它从被拒绝的失败轨迹切入，将其拆解为独立步骤，依据不确定性打分并结合元思考生成替代路径。在 DeepMath-103K 难题库中，DART 在相同生成开销下比传统采样多恢复了 37% 的难题，且生成合格轨迹的单条成本降低了 30%。

值得关注的点：该研究证明了“失败是成功之母”在大模型 post-training（后训练）中的工程落地价值。对于正在探索长链条推理、Math AI 以及自动代码修复的团队来说，这种利用失败轨迹重新采样的方法极具借鉴意义。

How Much Do Coding Agents Over-Edit, and Why? 代码 Agent 补丁归因与过度修改实证研究

核心贡献：研究团队开发了 Delta Residue Attribution (DRA) 归因回放工具，对 18 个前沿大模型在 SWE-bench Verified 和 DeepSWE 上生成的 7,660 条 GitHub Copilot CLI 补丁轨迹进行了精确到代码块的逐行删减与自动化测试校验，首次给出了 Agent 补丁膨胀的真相。

值得关注的点：打破了业界关于“Agent 喜欢盲目多写垃圾代码”的既有偏见。数据显示 Agent 增加的代码多数在补充测试集和文档，且核心逻辑代码的必要性（95% 以上）完全不亚于人类程序员。这为开发者使用 AI 编程工具提供了坚实的数据信心。

Toward Agentic Robotics: 大型机器人在 Agent 胶水层（Harness）设计上的系统性实证

核心贡献：针对“VLM 擅长长程规划但缺乏 3D 感知，VLA 擅长快速控制但缺乏记忆”的矛盾，该论文开展了具身智能领域迄今最大规模的胶水层（Harness）设计研究。在 8 个仿真基准、6 个 VLM 和 15 个 VLA/WAM 检查点上运行了超过 470,000 次实际部署。

值得关注的点：系统化总结出了多模态大脑与底层控制手臂之间的最佳组合范式与通信接口设计。搞具身智能研发的团队绝不能错过这篇充满工程踩坑经验与定量数据的避坑指南。
