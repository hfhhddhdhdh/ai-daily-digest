🔬 值得深挖

RoboArchitect: Automating the Design of Robotic Agents with Persistent Memory

核心贡献：提出了 RoboArchitect 框架，在冻结机器人底层控制策略（Policy）的前提下，利用代码模型自动迭代演进 Agent Harness（外壳框架）。在未见过的场景和任务上，成功率提升了 3.2 到 4.5 倍。

值得关注的点：不用重训动辄几十亿参数的机器人权重，仅靠外层 Agent 代码演化就能大幅提升泛化能力，为具身智能快速适配新场景开辟了极低成本的新路径。

Latent Sparse Attention (LSA): Subquadratic Ultra-Long Context Attention

核心贡献：针对百万级（1M+）超长上下文导致的全注意力机制计算爆炸问题，提出了 Latent Sparse Attention。通过在隐空间构建分层聚类树，实现了亚二次方（Subquadratic）复杂度的长文本注意力计算。

值得关注的点：彻底打破了 Transformer 处理长文本的计算瓶颈，不仅能在预训练模型上微调蒸馏，还能原生训练，是解决长文本 Agent 记忆与推理成本的关键突破。

ROOF: Learning Humanoid Fall Recovery under Overhead Constraints

核心贡献：提出 ROOF 强化学习方法，解决了双足人形机器人在上方有障碍物遮挡、空间受限条件下的跌倒复位与站立问题。在 Unitree G1 实体机器人上实现了 95/150 的高难度复位成功率。

值得关注的点：纯靠本体感觉（Proprioception）就能在受限空间内解算避障与起立动作，极大增强了人形机器人在复杂真实环境下的鲁棒性。
