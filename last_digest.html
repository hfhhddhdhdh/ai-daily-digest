🔬 值得深挖

Z-sight: 统一视觉-语言-动作（VLA）与隐空间世界模型

核心贡献：论文提出了一个统一的机器人基座模型 Z-sight，将 VLA 控制与自生成隐空间世界模型结合。它避开了传统视频世界模型高昂的像素级渲染成本，直接在 VLM 感知当前环境的视觉 Token 空间内预测未来，并在宇树 G1 人形机器人等多项任务上实现了 73.3% 以上的成功率。

关注理由：具身智能领域长期在“直接输出控制指令（VLA）”和“生成未来预测画面（世界模型）”之间割裂。Z-sight 证明了不画像素图、直接在隐空间里预测未来动作，既省算力又能大幅提升机器人在复杂环境下的控制精度。

CAR：解构 AI 科研创意的 Agentic 组合框架

核心贡献：针对大模型写科研 Proposal 容易流于表面和胡诌的问题，CAR 框架通过文献构建语义知识图谱，并引入类比、双重联想（Bisociation）、探索与细化四种显式算子，能够追溯科研设想的演进过程，并在LiveIdeaBench 上取得了显著高于传统 Single-shot Prompt 和 AI Scientist 的方法创新度。

关注理由：科学研究 Agent 正在从简单的“帮你读文献”迈向“帮你产生真正的学术 Hypothesis”。这种基于知识图谱算子的可追溯生成路线，比单纯靠大模型“幻觉”脑洞要靠谱得多。

作者：Sebastian Raschka (Ahead of AI) · 2026-11-15

为什么大模型能处理几十万甚至上百万 Token 的超长上下文？秘密全在位置编码的架构设计里。AI 领域著名科普作者 Raschka 这篇文章用最直观的图解和代码，把 RoPE、ALiBi 以及最新的长文本拓展技术彻底讲透了，非常适合想搞懂模型底层长文本机制的开发者。

  • 传统绝对位置编码（绝对坐标）在超出训练长度时会彻底失效，而旋转位置编码（RoPE）通过复数空间向量旋转，完美实现了相对位置关系的自然外推。
  • 长文本扩展并不是简单地把窗口拉长，扩展 RoPE（如 Dynamic NTK-aware 缩放）本质上是在频域上对位置信息进行重采样，避免高频注意力弥散。
  • 不同位置编码直接决定了大模型在 Agent 场景下检索海量上下文（如 Needle In A Haystack）的精度和计算复杂度上限。
