🔬 值得深挖

UniWALM: Unified World Action Language Model for Embodied Robot Control

核心贡献：将视频、动作和语言三种模态统一在一个Mixture-of-Transformers骨干网中，通过多模态同步去噪和闭环语言记忆，实现了无外部规划器的具身机器人控制。
关注点：它打破了传统将VLM和机器人动作流水线割裂的做法，用“语言作为记忆”的思路解决了具身智能的长序列上下文难题，值得所有机器人算法团队精读。

Beyond the Sequentiality Bottleneck: A Hybrid Diffusion-Autoregressive Framework for Efficient Multimodal Reasoning

核心贡献：提出了CoRAL混合框架，由扩散语言模型（DLM）并行生成多种推理轨迹规划，再由大型自回归模型（ARM）执行最优解，完美克服了自回归模型在长推理上的“顺序瓶颈”。
关注点：该研究为多模态推理的提速指明了新方向，用扩散模型的并行优势对冲自回归模型的慢速缺陷，兼顾了效率与质量。

Cache Engineering for Agents

核心贡献：针对LLM智能体在长轨迹交互中KV Cache I/O和存储成本爆炸的痛点，提出了“缓存工程”（Cache Engineering），允许Agent直接控制活跃缓存而无需重新填充前缀。
关注点：这是通往复杂、长周期AI Agent落地的重要工程突破，直接帮企业省下了巨额的算力和显存开销。
