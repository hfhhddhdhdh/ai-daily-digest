🔬 值得深挖

Agent 架构演进史：从脆弱的线性提示词链到代码执行级框架

核心贡献：系统梳理了智能体底层支撑架构（Agentic Harnesses）从早期的简单提示词链（Chains）、图结构工作流（Graphs），到如今具备自验证能力的代码执行级框架的演变脉络。
值得关注的点：文章直指链条结构的脆弱性，并指出通过代码执行来验证模型输出是兼顾系统可靠性、运行速度和成本的最优解，为工业级 Agent 架构设计提供了教科书级别的避坑指南。

AKV: SGLang-Based Serving System for Cache Engineering in LLM Agents

核心贡献：清华大学研究团队针对大模型智能体在多轮长对话中由于重复总结和上下文冗余导致的性能瓶颈，提出了基于 SGLang 的 KV 缓存工程化服务器方案。
值得关注的点：该方案允许 Agent 在运行过程中直接对 KV 缓存进行丢弃和重新定位，实测在多个智能体基准测试中将平均成本砍掉近三成，是目前解决长文本推理吞吐与成本难题的极佳工程实践。
