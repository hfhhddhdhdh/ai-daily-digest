⭐ GitHub 高星新项目

yetone/magpie

⭐ 493 · 语言: Go · 标签: claude-code、llm、macos

是什么：这是一个能让你在 Mac 菜单栏把各种大模型和 Agent 任意组合的效率工具。你可以把 Codex 跑在 DeepSeek 上，或者把 Claude Code 套在 Kimi 底座上。所有大模型能力在一个地方随意混搭，免去频繁切换网页的痛苦。

为什么值得关注：它直接切中了开发者和重度用户的痛点——不想被某一个闭源大厂商的客户端死死绑定。对于想用开源或平替模型跑特定 Agent 任务的人来说，这个菜单栏入口极度轻量且高效，绝对是省钱提效的利器。

samyost1/3dicon

⭐ 319 · 语言: Python · 标签: 3d、animation、claude-code

是什么：输入一句简单的 Prompt，就能直接吐出带真实透明通道的循环动画 3D 图标。它作为 Claude Code 的一个强大 Skill 存在，打通了文本到高质量动效资产的直接转换通道。做设计和前端动效的小伙伴再也不用枯燥地手调 3D 关键帧了。

为什么值得关注：多模态和生成式设计正在从“图片”走向高交互、可用的“动态资产”。它展示了 AI Agent 插件化之后爆发的惊人生产力，让普通设计小白也能秒出高质量的动效素材。

saragordic/rooms

⭐ 217 · 语言: Swift · 标签: macos、productivity、window-manager

是什么：专为 Mac 用户设计的项目切换器，把你的每一个工作项目变成一个独立的“房间”。通过快捷键一键切换不同的窗口布局和项目现场，告别桌面上乱糟糟几十个重叠窗口。虽然不是纯 AI 项目，但它是 AI 时代多任务并行不可或缺的桌面效率骨干。

为什么值得关注：当 AI 帮我们同时开辟多个写代码、写文章、跑数据的任务时，窗口管理成了新瓶颈。这种把工作上下文打包管理的思路，正是未来人机协同高效作战的基础基建。

JohnHeibel/ClaudeAnimationBase

⭐ 128 · 语言: JavaScript · 标签: animation、p5.js

是什么：一个用 Claude 辅助生成手绘卡通动画的完整入门套件，底层基于 p5.js 和 p5.brush。内置了名为 Clawd 的特色角色、31 种预设情绪动作，以及喂给大模型的详细编写指南。它把复杂的创意动画变成了一场和 AI 的流畅对话。

为什么值得关注：用大模型直接生成能跑、好看的代码级动画，是多模态创意的新方向。独立开发者和搞创意编程的人可以用它快速搭出惊艳的视觉原型，门槛直接被腰斩。

georgeding/Relate

⭐ 101 · 语言: JavaScript · 标签: ai-assistant、mcp、memory、ollama

是什么：一个完全本地私有化部署的聊天参谋，专门负责记住别人说过的话以及你答应过的事。支持 Ollama 和各种 OpenAI 兼容接口，基于 MCP 架构把聊天记忆管理得井井有条。它就像一个时刻在线、绝不泄露隐私的私人赛博秘书。

为什么值得关注：大模型最大的痛点之一就是“记性差”或涉及隐私不敢上云。这种主打绝对隐私、自托管的轻量记忆中枢，正是本地部署玩家和注重隐私人士一直在找的理想伴侣。

michaelswissa/jevry

⭐ 98 · 语言: TypeScript · 标签: ai-agents、browser-automation、electron

是什么：一个开箱即用的桌面端浏览器 Agent，基于 MIT 协议开源。它可以直接接管你的浏览器，帮你自动去网页上跑任务、查资料甚至打打支持的游戏。把浏览器的控制权彻底交给了后台的 AI 自动化流水线。

为什么值得关注：浏览器自动化正在从大厂专属的复杂框架下沉到桌面开源端。搞研究、爬数据或者日常网页重复操作的人，可以用它直接解放双手，体验 Agent 时代的网页代打爽感。

yukitorido/short-video-generator-AI

⭐ 63 · 语言: Python · 标签: ai、opus-clip、short-video-automation

是什么：一套开源的自动化短视频生成流水线，专门用来批量制作竖屏短视频。整合了大语言模型、Whisper 语音转文字、高光时刻自动检测和剪辑脚本。无需复杂的专业剪辑软件，全靠 Python 和 AI 自动挑重点切片。

为什么值得关注：短视频运营和自媒体矩阵现在极度依赖自动化工具来降本增效。这是一个典型的、可本地运行的商业级工作流替代品，对做内容分发和切片的玩家来说非常有实用价值。

asokurasu/text-humanizer

⭐ 54 · 语言: Python · 标签: ai-detector、ai-detector-bypass、text-humanizer

是什么：一个完全免费开源的项目，用多语言大模型重写流水线，专门把机器味十足的 AI 文本“人文化”。它可以帮你绕过市面上各种严格的 AI 文本检测器（如 ZeroGPT 等），把机器腔调洗成流畅的人话。

为什么值得关注：随着高校和企业对 AI 生成文本的查重与拦截越来越严，反检测和文本润色成了刚需。这个开源方案直接把原本收费的商业防检测工具打成了白菜价，引发了关于内容合规与反制的新一轮博弈。
