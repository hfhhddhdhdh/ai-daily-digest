⭐ GitHub 高星新项目

ezmoney4scout/pixel-office

⭐ 88 · TypeScript · 像素风智能体看板

是什么：这是一个专为 Windows 设计的桌面端可视化 AI 智能体团队协作应用，采用复古的像素风办公室 UI。它能让不同的 AI 模型在办公室里协同工作，自动帮你炮制 PowerPoint、Word、Excel 和 PDF 文件，所有关键行动在执行前都需要经过你的老板键审批。

为什么值得关注：它把冷冰冰的命令行和后台 API 变成了一个像“宝可梦”或者“模拟人生”一样的可视化像素办公室，极大地降低了普通人管理多 Agent 协作的门槛。你可以自由切换各个 AI 的底层模型 API 密钥，好玩且实用，是体验多 Agent 协同的绝佳桌面玩具。

michaelswissa/jevry

⭐ 100 · TypeScript · ai-agents、browser-automation、desktop-app

是什么：这是一个基于 MIT 协议开源的桌面端浏览器自动化智能体（Browser Agent），基于 Electron 构建。它能直接接管你的浏览器，自动帮你在全网抓取信息、开展网页研究、处理复杂表单甚至协助玩某些支持的游戏。

为什么值得关注：相比于那些藏在云端的黑盒自动化工具，这是一个能在你本地桌面上直接跑、完全开源且受控的网页操作助手。对于需要日常做海量竞品调研、网页信息搜集的打工人来说，这是一个解放双手的好东西。

leter/zh-tech-writing

⭐ 88 · 无 · agent-skills、chinese、claude-code、documentation

是什么：这是一个专为 Claude Code 等编程 Agent 定制的中文技术文档写作技能包（Agent Skill），核心规范脱胎于阮一峰著名的《中文技术文档的写作规范》。它教会 AI 如何在写中文时戒掉官腔套话、多用短句、保持平实自然。

为什么值得关注：现在用 AI 写技术文档的人极多，但绝大多数都带着浓重的“AI 翻译腔”与废话。这个项目相当于给你的编程 Agent 植入了“去 AI 味”的灵魂，非常适合所有苦于大模型中文表达太官方、希望代码注释和技术文档更地道的人。

jankeesvw/omarchy-meeting-recorder

⭐ 136 · Rust · gtk4、meeting-recorder、speaker-diarization、transcription

是什么：一款用 Rust 写的本地会议录音与转写桌面应用，基于 GTK4 和 Libadwaita 构建。它能够把麦克风声音和电脑内部音频录制为独立的两条音轨，完全在你的本地电脑上跑语音转写、说话人分离（Diarization）以及章节切分。

为什么值得关注：在各大厂商疯狂把会议记录往云端传、存在隐私泄露风险的当下，这个完全在本地运行的 Rust 工具简直是注重隐私的极客和远程办公族的福音。它把高性能的本地音频处理封装成了开箱即用的优美桌面软件。

bridge-mind/bridgeclip

⭐ 145 · TypeScript · 开源 AI 视频剪辑

是什么：由 BridgeMind 团队开源的 AI 视频切片桌面端应用，旨在帮创作者快速处理长视频并精准切出适合短视频平台传播的高光片段。它把繁琐的剪辑工作流用 AI 算法进行自动化封装。

为什么值得关注：多模态和视频生成大火之后，内容创作者最缺的就是能高效处理视频流的本地化工具。这个开源项目的出现，给独立自媒体和剪辑工作室提供了一个摆脱高额商业软件订阅费的平替方案。
