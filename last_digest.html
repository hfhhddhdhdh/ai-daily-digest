🔬 值得深挖

FrontierPhysics：评估 AI 智能体能否完成端到端物理前沿研究

核心贡献：由 42 位物理学家基于自身真实科研项目联合打造，包含 56 个涵盖理论、计算和实验物理的端到端研究任务。要求 Agent 自主查文献、制定方案、做实验并撰写可发表级别的学术论文。

关注点：测试了 22 个模型在 26 种配置下的表现，没有一种配置能通过超过 27.3% 的任务测试。人工审查发现，目前顶级 Agent 的核心短板在于无法维持足够严密的多步逻辑推理，常常在实验中途盲目自信或逻辑脱节。做简单代码补全容易，真做科研还是差点火候。

CompressionBench：把大模型量化剪枝交给代码 Agent 自己做

核心贡献：构建了首个测试代码 Agent 能否自主压缩大模型的基准。给 Agent 一个原始模型权重、存储上限和测试环境，让它自己设计压缩算法并编写可执行推理代码。

关注点：在 36 次测试提交中，有 29 次成功通过了独立验证。最优 Agent 架构压缩出的模型在下游任务上拿到了 77.33% 的准确率（原始模型为 79.56%）。这证明了在自我递归提升（RSI）的链条上，大模型完全有能力自主优化后续小模型的部署体积。

📖 今日推荐博客

How big is the open model economy today?（当下的开源模型经济到底有多大？）

Nathan Lambert / Interconnects · 2026-11-04

开源模型到底能不能赚到钱？著名 AI 研究员 Nathan Lambert 撰文深入剖析当前开源大模型的真实商业生态，打破“开源就是免费打白工”和“闭源必然垄断”的两种极端迷思。

  • 开源模型正快速吞噬企业级应用市场，但商业价值捕获依然高度向 API 托管平台（如 Together/Anyscale）和云巨头倾斜，纯模型提供商极难直接变现。
