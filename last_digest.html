🔬 值得深挖

SciMARS：基于多智能体递归自我提升的闭环科学探索框架

核心贡献：针对多 Agent 系统在长期科学探索中丢失记忆、重复犯错的痛点，设计了共享证据图谱（Evidence Graph）与组件编辑器，实现了角色分工和记忆策略的动态自适应调整。
关注点：在 Autonomous Science Bench 上，配合 GPT-6-Astra 将科学难题解决率从 8/18 提升到了 12/18，展现了多 Agent 系统自我进化解决前沿科研问题的潜力。

AuDiR：诊断音频推理瓶颈的规则与感知干预评估法

核心贡献：拆解多模态音频模型到底分不清是“听不清”还是“不懂规则”。通过对输入端加入声学观察描述和规则提示，对 Gemini-3.8-flash 等模型进行系统诊断。
关注点：测试显示 Gemini-3.8-flash 在盲猜时准确率仅为 29.3%，但一旦直接提供声学观察事实，准确率狂飙至 98.5%。这表明当前多模态音频模型的短板主要在低层声学特征提取，而非高层逻辑推理。

Phrase-Level Speculative Decoding：短语级投机解码加速 LLM 推理

核心贡献：打破传统投机解码受限于分词器（Tokenizer）单个 Token 的局限，设计了一个小型 MLP 头，直接预测 1-3 个词组成的常用短语并映射回目标 Token。
关注点：无需修改或重新训练主模型，以极低的微调成本突破了 BPE 分词器对连续词组投机生成的固有阻碍，为大模型实时推理提速开辟了新思路。
