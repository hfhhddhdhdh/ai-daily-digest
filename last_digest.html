🔬 值得深挖

4DCodeBench: Benchmarking Agents on Inverse Graphics of Dynamic Scenes

核心贡献：论文引入了一个全新的 4D 逆向图形学代码生成评测集。传统的 3D 重建只需要静态还原，而这个基准要求 Agent 通过编写物理仿真代码来重建视频中的“动态场景”（如形变、液体流动、碎裂等）。

值得关注：这是检验 AI 能否理解现实物理世界动态规律的终极考卷。测试表明，目前即使是最强的大模型在物理动态重建上也表现拉胯，这也是具身智能和物理模拟 Agent 接下来必须攻克的硬骨头。

EyeRobot 2.0: Active Gaze for Precise Manipulation without Wrist Cameras

核心贡献：模拟人类视觉，推出了一套只用单双目相机、不需要手腕相机的机械臂精准抓取框架。EyeRobot 2.0 可以主动转动两只“眼睛”锁定场景中的三维注视点，并把更多计算资源（Visual Tokens）倾斜分配给视野中心，大幅降低了空间操作的计算延迟。

值得关注：手腕相机容易坏且有视觉死角，EyeRobot 2.0 证明了“精细注视”完全可以靠算法和主动头部旋转来平替，对于降低机器人硬件成本、提高抓取鲁棒性意义重大。

FinSkillBench: Knowledge or Calculator? Decomposing the Skill Premium in Verifiable Financial Agent Workflows

核心贡献：金融 Agent 测试集 FinSkillBench 包含了 12 个子任务、2603 个测试场景，自带隐藏的可再生标准答案和判定机制。研究发现：给 Agent 投喂现成的“技能工具包”能提分 16.2，只给它阅读文档只提分 5.6。

值得关注：这打破了“多看资料模型就会做”的迷思。对于金融、医疗等严谨领域，给 Agent 配个“计算器”和执行工具，比指望它自己临时去推理写出逻辑要管用得多，工具外挂才是硬道理。
